#  Аналіз динаміки народжуваності в Україні (2005–2025 рр.)

## Про проєкт

Проєкт присвячений аналізу довгострокових регіональних трендів народжуваності в Україні та оцінці демографічного впливу повномасштабної війни на основі офіційних даних Державної служби статистики України та оперативних даних Міністерства юстиції.

У межах проєкту досліджено:
* загальну динаміку та багаторічні тренди народжуваності в Україні (2005–2025 рр.);
* регіональний розподіл та інтенсивність народжуваності на інтерактивній карті;
* визначення пікових періодів демографічного розвитку (максимум у 2012 році);
* оцінку кризового шоку та падіння показників у 2022–2023 роках (зниження на -31.10% порівняно з довоєнним 2021 роком);
* порівняння поточних показників із довоєнними базовими значеннями (на прикладі 2021 року);
* побудову ключових KPI-показників та виявлення регіонів-лідерів.

Проєкт включає підготовку та очищення даних (роботу з дублями та статистичними виносками через текстові функції), описакову статистику, географічний мапінг, візуалізацію даних у Tableau та формування глибоких аналітичних висновків.

* Tableau Public (розробка дашборду, інтерактивні фільтри, LOD-вирази, подвійні осі)
* PostgreSQL / SQL (трансформація та об'єднання даних через `UNION ALL`)
* Очищення та підготовка даних (нормалізація назв регіонів, усунення зірочок/виносок Держстату)

* Географічний аналіз (мапінг регіонів України)
